# Requisitos — Proyecto Final (Ruta Avanzada)

Transcrito del PDF "Proyecto Final Avanzado" (Jóvenes creaTIvos), 12 páginas.

**Mi emprendimiento digital:** una aplicación web full stack funcional, publicada en internet y con inteligencia artificial personalizada para el negocio.

## Entregables (lo mínimo para la defensa)
1. **App publicada:** URL funcional en internet.
2. **Repositorio GitHub:** código organizado y con historial.
3. **Marca + home:** identidad visual y página de inicio.
4. **Catálogo:** productos o servicios del emprendimiento.
5. **Contacto real:** formulario funcional.
6. **Admin con login:** panel privado para gestionar información.
7. **IA personalizada:** chatbot, recomendador o generador adaptado.

## Arquitectura esperada
- Flujo: Marca (home) → Catálogo (productos/servicios) → Contacto (formulario real) → Admin (login + panel) → IA (funcionalidad útil).
- **Frontend:** interfaz responsive, componentes reutilizables, estados de carga y validaciones.
- **Backend + datos + IA:** APIs y base de datos, autenticación para admin, IA adaptada al emprendimiento.

## Criterios de calidad avanzada
| Código limpio | UX cuidada | IA personalizada |
|---|---|---|
| Separación frontend/backend | Responsive real | Conoce productos |
| Carpetas claras | Animaciones básicas | Usa tono de marca |
| Comentarios técnicos útiles | Errores claros | Responde como el negocio |
| Otro dev puede entenderlo | Estados de carga | Genera textos listos |

## Reglas
- Se permiten librerías para colocar animaciones en la página.
- Control de versiones con Git: **mínimo 15 commits**.
- Subir a repositorio de GitHub.
- Desplegar el resultado en **GitHub Pages**.
- Debe ser responsive.

## Forma de trabajo
- Individual o en pareja; ambos deben dominar el código.
- La defensa incluye preguntas para todo el equipo.

## Ruta de construcción (referencia)
Junio: IA + lógica + Git · Julio: HTML + CSS · Agosto: JavaScript + Backend · Septiembre: Backend + React · Octubre: React + IA · Noviembre: proyecto integrador (finalizar y defender).
